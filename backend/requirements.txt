# Runtime dependencies.
#
# Every entry carries an upper bound. Without one, `pip install -r` resolves
# differently every month and the published numbers stop being reproducible --
# which is the one property this project is built around. The bounds are the
# compatibility envelope. requirements.lock records the exact set the API image
# was built and verified against; regenerate it with `make lock`.
#
# pulp is the concrete case: 4.0 removes both `LpVariable(name, ...)` direct
# construction and `PULP_CBC_CMD`, and the maintenance agent uses both. An
# unbounded `pulp>=2.8` would have picked that up silently on the next clean
# install and broken scheduling outright.

uvicorn>=0.34,<1.0
pydantic>=2.9,<3.0
# Never imported directly. FastAPI needs it to parse multipart/form-data,
# which is how /quality/inspect receives an UploadFile -- without it those
# routes fail at request time, not import time.
python-multipart>=0.0.12,<0.1

lightgbm>=4.5,<5.0
scikit-learn>=1.5,<2.0
